# 🚀 [Car Model Prédiction] – Machine Learning

## 📌 Description

Ce projet consiste à développer un modèle de **Machine Learning** permettant de prédire l'état d'un véhicule en vente en fonction des variables de marque, année de mise en circulation, la transmission(Manuel, automatique), le quartier où se vend le véhicule et son prix.

---

## 🎯 Objectif

* Construire un modèle performant de [classification / régression]
* Optimiser ses performances
* Déployer une application interactive

---

## 📊 Données

* Source : [Kaggle ]
* Taille : [5 507 lignes]
* Variables principales :

  * Marque
  * Année
  * Boîte de vitesse
  * Adresse
  * Prix


---

## ⚙️ Méthodologie

### 🔹 Étapes

1. Nettoyage des données
2. Encodage des variables catégorielles
3. Normalisation
4. Séparation Train/Test
5. Entraînement du modèle
6. Évaluation
7. Déploiement

---

## 🤖 Modèles utilisés

* Random Forest
* XGBoost
* KNN

---

## 📈 Résultats

| Métrique  | Score |
| --------- | ----- |
| Accuracy  | 0.92  |
| Precision | 0.90  |
| Recall    | 0.89  |
| F1-score  | 0.90  |
